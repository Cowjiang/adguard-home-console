# Tauri 2 壳

**Status:** current
**Updated:** 2026-10-15

`src-tauri/` 把同一个 React 前端装进系统 WebView，并用 Rust 复刻 Express 代理的传输语义，使 Web 与壳内共用页面，同时不依赖浏览器的同源代理。

代码入口：`src-tauri/src/lib.rs`、`src-tauri/src/proxy.rs`、`src-tauri/tauri.conf.json`、`src-tauri/plugins/tauri-plugin-system-components/`。

## crate 结构

- 包 `adguard-home-console`，库名 `adguard_home_console_lib`（`staticlib`/`cdylib`/`rlib`，Tauri 移动端约定），二进制只调用 `run()`。
- 模块面很小：`src-tauri/src/proxy.rs` 承担全部网络逻辑，`src-tauri/src/lib.rs` 负责注册命令、debug 登录注入与 iOS 专属处理。
- 依赖 tauri 2、reqwest（rustls，不走系统 TLS）、tokio（proxy 单测自起 TCP）、thiserror；iOS 侧补 `objc2`。
- `Cargo.toml` 只有一处补丁：`tauri-plugin-system-components` 指向本仓 `plugins/` 下的实现。`tao` 的补丁已于 2026-10-07 退掉——iOS 27 需要的 #1245 修复（scene 配置被提前释放，只在 release 构建暴露）已随 tao 0.37 进入上游，而 tauri 2.12 的 `tauri-runtime-wry` 依赖该版本。
- **crate 与 npm 必须同 minor**：Tauri CLI 在 `build`/`dev` 上比对 `tauri` crate（取自 `Cargo.lock`）与 `@tauri-apps/api`（取自已安装依赖）的 major/minor，不一致直接中止。当前两侧都是 2.12；升一侧时必须同时升另一侧，`@tauri-apps/cli` 也随之同 minor。

## 命令面

`invoke_handler` 只注册两条命令：

| 命令 | 行为 |
| --- | --- |
| `agh_fetch(method, target, auth_header, path_with_query, body_json)` | 发起一次 AGH 请求，返回 `{status, content_type, body_text}` |
| `get_debug_login()` | 仅 debug 构建返回环境变量里的连接信息，release 恒为 `None` |

`agh_fetch` 与 Express 代理实现同一份前端契约（`src/lib/api.ts`，场景夹具 `contract/agh-proxy.contract.json`，由 `cargo test` 内的 runner 与 `npm run test:server` 分别验收）：

- target 必须是 http(s)，只取 origin，target 自带路径丢弃；
- 路径归一：`/api/agh` 前缀换成 `/control`，已带 `/control` 的原样，其余补 `/control/` 前缀；
- 只发 `Authorization`（非空时）与 `Content-Type: application/json`（非 GET/HEAD），body 缺省 `{}`；
- 上游 301/302/307/308 手动跟随最多 3 跳，只更换 origin 且**仅限同主机名**（scheme/port 可变）；跨主机的跳转返回 502，不把 `Authorization` 重放给别的主机；
- 超时 25 秒，按剥除 query 后的路径段判定；路径含 `/filtering/refresh` 时 120 秒；
- 失败不返回 `Err`，而是产出 `{error, kind}` JSON 与 400/502 状态码（`kind` 枚举见 `proxy.rs`，文案在前端 i18n），由前端统一处理；响应体原样透传，不在 Rust 解析 JSON；
- 与 Express Adapter 的允许差异：无请求体大小上限（本地 IPC），`content_type` 字段目前前端未消费。

## 权限

- 唯一 capability `default`：窗口 `main`，权限 `core:default` + `system-components:default`。
- 插件默认权限集覆盖 19 条 `allow-*`：tab bar 7 条、sheet 2 条、component 4 条、appearance 1 条（`allow-set-appearance`）、listener 2 条、glass 3 条。
- 新增命令必须同时登记：插件 `build.rs` 的 `COMMANDS`（生成 autogenerated 权限）与 `permissions/default.toml`；只加 `invoke_handler` 会让 `invoke` 被静默拒绝。

## system-components 插件

`src-tauri/plugins/tauri-plugin-system-components/` 是本仓维护的 Tauri 插件（上游 v0.1.8 的本地分支，增加了 `appearAnimation`），为壳提供原生 UI 叠加层。**上游基线与逐条 delta 清单在 `src-tauri/plugins/tauri-plugin-system-components/FORK.md`**，`scripts/plugin-fork-diff.sh` 一条命令输出当前 delta；delta 保持纯加法，便于上游发版时机械重放。

- 命令面 17 条：TabBar（configure / remove / show / hide / select_tab / set_badge / get_tab_bar_insets）、Sheet（present / dismiss）、组件（create / update / update_components / remove）、外观（set_appearance）、玻璃（is_glass_supported / set_window_glass / clear_window_glass）。壳实际只用到其中 10 条权限（tab bar 4、组件 3、外观 1、listener 2）；未用到的上游能力（sheet、badge、window glass、Android）按原样保留，不做裁剪。
- 本地相较上游新增的能力（`appearAnimation` / `appearDuration` / `appearOffsetX`、按钮 `foreground` 内容色、`accessibilityLabel` 朗读文案、`alpha` 淡出、`set_appearance`）在 `src/types/system-components.d.ts` 有类型补充；npm 包类型未跟版。iOS 26 的 glass 按钮配置忽略 `baseForegroundColor` 对符号图的着色，符号色由插件用 `withTintColor(_:renderingMode:.alwaysOriginal)` 施加。这些属性目前只有 iOS 实现：`desktop/macos/components.rs` 与上游一致，macOS 上 `alpha`/`appear*`/`foreground`/`accessibilityLabel` 会被忽略。
- `permissions/autogenerated/**` 与 `permissions/schemas/schema.json` 是插件构建时生成的产物，已不跟踪（见插件 `.gitignore`）；`permissions/default.toml` 手写并保留。
- 平台分工：iOS 全量实现，Android 只有 sheet，非 macOS 桌面一律返回 `Unsupported`，macOS 由 `tab_bar.rs`、`components.rs`、`window_glass.rs` 三块实现。
- 事件通道分两套：macOS 走 Tauri 事件，iOS 走插件通道；前端经 `@sosweetham/tauri-plugin-system-components-api` 调用，本地类型补充在 `src/types/system-components.d.ts`。

## 窗口与构建

- `src-tauri/tauri.conf.json`：productName `AGH Console`、identifier `com.cowjiang.aghconsole`、version 与 `package.json` 同值（发版时由 `release-plan.mjs --set-version` 一起写）、单窗口 `main`（960×640，最小 400×600）；`frontendDist` 指向 `../dist`，devUrl 为 5173。
- `beforeDevCommand`/`beforeBuildCommand` 复用 pnpm 脚本，壳与 Web 构建同一份 `dist/`。
- iOS 在 setup 中禁用 WKWebView 的前进/后退手势，页面转场由前端自己负责（见 `docs/web-interaction.md`）。
- `src-tauri/gen/` 只生成 apple 一套工程且不入库；生成与构建统一走 `./scripts/ios-signing.sh`，签名值来自被忽略的 `.env.signing`。
- `src-tauri/Cargo.toml` 的 `[profile.release] debug = true` 是 **iOS release 链接的必需项**：swift-rs 依 cargo 的 `DEBUG` 选 Swift 编译配置，而 Swift 的 Release 配置（`-O -whole-module-optimization`）会把非 `public` 的 `@_cdecl` 入口降为 private external，静态归档解析不到，设备链接报 `_register_plugin` / `_init_plugin_system_components` 等未定义；Debug 配置保持 external。Xcode 的 release strip 会剥掉最终二进制的调试信息（ipa 约 3.4 MB，与开关无关）。上游把这些入口改成 `public`（或 swift-rs 不再优化这段胶水）后即可移除；移除前设备 release 构建必然失败。
- `scripts/ios-deploy.sh` 安装 `src-tauri/gen/apple/build/arm64/AGH Console.ipa` 到已连接的真机；bundle id 从 ipa 里读，渲染进工程的是 `.env.signing` 的 `AGH_BUNDLE_ID`（`tauri.conf.json` 的 `identifier` 只作为 CI 的兜底，两者与仓库变量应同值，见 [原生平台现状](../native-platforms.md)）。Personal Team 首次安装后需在设备上「设置 → 通用 → VPN 与设备管理」信任开发者证书，否则启动被系统拒绝。
