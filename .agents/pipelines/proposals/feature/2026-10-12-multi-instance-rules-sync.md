# 为多实例增加 DNS 重写与自定义规则单向同步

**Class:** feature
**Status:** implemented
**Date:** 2026-10-12
**Source:** 竞品功能调研与多实例运维场景反馈。对标 `adguardhome-sync` 等专用同步工具的核心高频功能。

## Goal

在多实例部署（如主备双 DNS）环境中，用户往往需要保证多台 AdGuard Home 实例的域名重写列表（DNS Rewrites）和自定义过滤规则（User Rules）保持一致。
当前控制台各实例配置完全独立，用户在一个实例上录入或修改规则后，必须手动切换实例重复录入，操作繁琐且极易出现双机规则漂移不一致。
本提案旨在提供「一键推送到其他实例」的手动同步功能，在不需要常驻后台服务的情况下，满足大部分用户的即时双机同步诉求。

## Decision

- **同步范围（MVP 范围聚焦）**：
  - 聚焦用户日常维护频率最高、且不与单机硬件绑定的两类核心配置：
    1. 自定义过滤规则（`user_rules`，通过 `/filtering/config` 读写）；
    2. DNS 重写规则（`rewrite/list`，通过 `/rewrite/add` 与 `/rewrite/delete` 或批量更新接口操作）。
  - 不涉及 DHCP 租约等单机物理网络绑定项，保证轻量安全。
- **用户交互与确认流**：
  - 在自定义规则页（`CustomRulesPage`）与 DNS 重写页（`RewritesPage`）右上角操作区增加「同步到其他实例」按钮（仅在 `instances.length > 1` 时显示）。
  - 点击后弹出「规则同步」Sheet/弹窗，列出其他已配置的在线实例供勾选目标，并明确告知覆盖策略（以当前活跃实例规则完全覆盖目标实例对应规则）。
- **执行与容错机制**：
  - 采用当前实例数据拉取 -> 目标实例批量覆写流程。
  - 同步前目标实例状态校验，若不可达或凭据失效给出明确报错，不影响其他成功实例。
  - 同步完成后通过 Toast 提示同步结果，并自动使对应目标实例的 SWR 缓存失效。

## Accept

- [x] 仅当实例数量 >1 时在自定义规则与 DNS 重写页展示「同步到其他实例」入口。
- [x] 同步弹层支持选择/勾选目标实例，并展示二次确认防误操作。
- [x] 成功将当前实例的自定义规则或 DNS 重写列表完整推送并覆盖到目标实例。
- [x] 遇到离线或鉴权失败的目标实例时，给出友好的差异化提示，不阻断其他实例。
- [x] 补充前端单元测试，验证规则同步流程的数据组装与容错逻辑。
