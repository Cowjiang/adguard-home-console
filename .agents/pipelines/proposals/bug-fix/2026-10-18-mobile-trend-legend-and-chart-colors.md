# 让移动端趋势卡不再与图例打架，并统一图表的语义配色

**Class:** bug-fix
**Status:** implemented
**Date:** 2026-10-18
**Updated:** 2026-10-18（实现完成，补验收结论与扫描数据）
**Source:** 承接 `2026-10-17-mobile-overview-en-overflow.md` 的 Note（趋势卡图例互叠，当时按用户决定未动）；用户 2026-10-18 连轮预览后定稿

## Goal

上一提案留下的两处问题，加一处配色语义不统一：

- 英文下移动端流量趋势卡的图例与标题、时间选择器抢位置：390px 标题溢出 26px、`Malware & phishing` 与 `Adult websites` 两图例项互叠 328px²；四项英文标签本身在 390px 内也排不下（需 291px，标题+选择器之外的余量约 120px）。
- 趋势图里「拦截」用蓝色（`--chart-2`），而构成图、拦截榜单都用红色，同一含义在不同卡片里颜色不一致，读图要靠文字。

## Decision

- **移动端趋势卡不显示图例**：四项序列改用既有的长按预览识别（预览已按序列色显示名称与数值，颜色与卡片一致）；桌面保持标题右侧的两项图例不变。评估过并撤回的三个中间形态：标题下方单行排开、图内左上角四行（无底/带半透明卡片）、限宽折行——都仍然占位或压数据，用户最终选择「移动端不显示」。
- **趋势图的拦截序列改用 `--danger`**（图表内 `--chart-2` 局部重映射 + 桌面图例圆点同步），与构成图、拦截榜单的红色一致；查询=绿、恶意/钓鱼=琥珀、成人网站=紫保持不变。
- 移动端构成卡的图例在上一轮去掉百分比列之后，本轮让名称列吃掉剩余宽度（容器 `flex-1`），数量贴卡片右边缘对齐，消掉右侧留下的空白块；桌面构成卡是内容宽度卡片，不受影响。

## Accept

- [x] 320–430px 中英文：趋势卡无文字互叠、无被卡片裁切的文字（英文专属命中 360–1280 全为 0，只剩已知的 320px 构成卡省略与设计内的上游地址省略号）
- [x] 桌面 1024/1280：趋势卡图例仍在标题右侧（两项，拦截圆点为红），构成卡仍带百分比列、卡片宽度与改动前一致（396.75px）
- [x] 移动端长按预览显示四项数值与序列色，图例缺省不影响识别
- [x] 移动端构成卡数量右对齐、右侧无空白；320px 的截断与改动前一致（既有边界）
- [x] `pnpm check` / `pnpm test`（115 passed）/ `pnpm build` 通过
